# RMI Fermentation Run, Fall 2026

Headspace Raman measurements on the Viticulture and Enology class fermentor at the UC Davis RMI winery, with the RPK-laser configuration of the HC-ARF instrument. Follows the instrument published in IEEE Trans. Instrum. Meas., vol. 75, 2026, Art. no. 7006218.

| Folder | Holds | In git |
|---|---|---|
| `analysis/` | Analysis scripts and tests; see `analysis/README.md` | yes |
| `app/` | Source of the Noise Test Log web app (published on claude.ai) | yes |
| `docs/` | Master copies of the plan, primer, README and checklist sent to Diego; the Box copies (`2026 Measurements\Communications and docs`) are what collaborators read | yes |
| `results/` | Running results across days (dark model, decision values) | yes |
| `data/` | Local copies of the spectra, by date, from Box | no |
| `log_export/` | Noise Test Log exports, by date | no |

Schedule: tank filled Friday 9 October (cold soak under house N₂); first measurements Saturday 10 October; regular schedule from Monday 12 October. Decision on laser power and integration time: Thursday 8 October, 12:00.
